# Práctica 5
Esta práctica contiene los programas que hice para la quinta práctica del curso de Introducción a Ciencias de la Computación.

## Contenido

## Parte 1: Calculando π
- EstimacionPi.java: programa que calcula una aproximación de π lanzando dardos imaginarios
- PrecisionPi.java: programa que sigue lanzando dardos hasta acercarse a π con la precisión que se le pide

## Parte 2: El señor Pines
- CotizadorPines.java: programa que calcula cuánto debe pagar un cliente por su préstamo, revisando antes que los datos estén bien y cambiando la tasa según el tipo de cliente

## Carpetas
- src: los programas
- bin: los programas ya compilados
- docs: el reporte en PDF
